Resume Builder API

Post resume data as JSON, get a print-ready A4 PDF back. The PDF is rendered by the exact templates the Resume Builder website uses, so anything a visitor downloads from the site and anything your integration generates look the same.

Quick start

Send a POST to /v1/resumes/pdf with a JSON body and the response is the PDF itself. A ready-to-run shell example is in README.md. 

# request
POST /v1/resumes/pdf
Content-Type: application/json

{ "fullName": "Suryanarayan Panda", "email": "you@example.com", "template": "modern" }

# response
200 OK
Content-Type: application/pdf
Content-Disposition: attachment; filename="Suryanarayan_Panda_Resume.pdf"

Endpoints

GET/v1/healthLiveness probe.
GET/v1/templatesAll template ids, names and categories.
GET/v1/schemaJSON Schema for the payload.
GET/v1/openapi.jsonOpenAPI 3.0 document, for code generators.
POST/v1/validateNormalise and validate without rendering.
POST/v1/resumes/previewHTML preview. Add ?full=1 for a standalone page.
POST/v1/resumes/pdfThe PDF. ?format=base64 returns JSON instead of bytes.

Payload

Only fullName and email are required; every other field is optional and simply omitted from the document when empty. Common aliases are accepted - name, objective, experience, education - so an existing form usually maps across without changes.

FieldTypeNotes
fullNamestringRequired, up to 120 characters.
emailstringRequired, must look like an address.
phonestringDigits, spaces, + ( ) - only.
address, linkedin, github, languagesstringPrinted in the contact block.
summarystringCareer objective or professional summary.
qualificationsarrayUp to 20 of {degree, university, year, score, status}.
edu_12th_*, edu_10th_*stringSchool, board, stream, year, score.
workExperience, projects, skills, certifications, actHobstring or arrayArrays are joined with commas.
templatestringAny id from /v1/templates.

Embed it on your site

sdk/resume-builder-connect.js is a dependency-free browser connector. Drop it in, point it at this API, and either call it directly or mount the ready-made form. 

<script src="resume-builder-connect.js"></script>
<script>
  const rb = ResumeBuilderConnect.init({ baseUrl: 'https://your-api.example.com', apiKey: 'optional' });

  // 1. Mount a form that collects details and downloads the PDF
  rb.mount('#resume-widget', { template: 'modern' });

  // 2. Or drive it from your own UI
  await rb.downloadPDF({ fullName: 'Asha Rao', email: 'asha@example.com' }, { template: 'classic' });
</script>
